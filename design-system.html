05 / Правила

Сохранять характер.

Применять

  • Локальные шрифты и промышленное медиа.
  • Графитовый текст на светлой поверхности.
  • Акцент для действий, точек и прогресса.
  • Keyboard focus и reduced motion.
  • Радиусы по масштабу: 8 / 18 / 40px.

Избегать

  • Коричневых стартовых переменных-заглушек.
  • Голубого мелкого текста на светлом фоне.
  • Декоративных теней у каждой карточки.
  • Новых шрифтов без необходимости.
  • Выдачи демонстрационных цифр за проверенные.
